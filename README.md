# Vade Launcher

Лаунчер адміністратора комп'ютерного клубу:
**адмін-панель на головному ПК + легкий агент (служба Windows) на кожному ігровому ПК**.
Працює повністю в локальній мережі, без хмари.

* **Інтерактивна карта клубу** (вигляд за замовчуванням): кожен ПК на своєму реальному столі, колір за станом
  (вільний / зайнятий / обслуговування / помилка / сон / offline / ще не доданий), картка при наведенні, меню дій по кліку,
  Ctrl+клік і вибір рамкою, зум і перетягування. Режим «Редагувати карту»: ПК, стіни, рамки зон й орієнтири на сітці, Undo/Redo, збереження в `map_layout.json`. Єдина світла/темна/системна тема.
* **Матриця ігор («Ігри в залі»):** інвентаризація Steam-бібліотек усіх ПК, позначення клубних ігор (`clubAppIds`), підсвітка чужих і відсутніх ігор, видалення чужої гри або доінсталяція через SteamCMD у один клік.
* **Швидка діагностика без AnyDesk:** список процесів ПК із CPU/RAM і завершення завислого процесу (з блокуванням критичних системних процесів), перезапуск Провідника Windows, миттєвий скріншот активної сесії.
* **Broadcast / Deploy + PIN-захист:** масове виконання PowerShell/CMD або роздача файлів по LAN (з перевіркою SHA-256) під захистом опціонального Admin PIN.
* **Діагностика в ZIP та готова «флешка агента» (.zip):** збір знеособленої діагностики адмінки й агента в один `.zip` та генерація ZIP-інсталятора з `preconfig.json`.
* **Автооновлення адмінки:** релізи GitHub Actions (`.github/workflows/release.yml`) + `electron-updater` у шапці та Налаштуваннях.
* **Мультимовність (i18n):** українська, польська та англійська мови інтерфейсу.
* **Нічний розклад, детектор зайнятості, швидке очищення після сесії, монітор здоров'я заліза, NTP-синхронізація, історія запусків та інтеграція із сайтом клубу.**

Документація: [архітектура й обґрунтування стеку](docs/ARCHITECTURE.md) · [протокол обміну](docs/PROTOCOL.md) ·
[інтеграція з сайтом + приклад Cloudflare Worker](docs/SITE_INTEGRATION.md).

## Структура

```
packages/protocol   спільні типи, протокол, розклад, валідація, автентифікація
apps/agent          агент → VadeAgent.exe + служба + install.cmd
apps/admin          адмін-панель (Electron + React)
.github/workflows   CI/CD збірка інсталятора та релізів GitHub
```

## Потрібно

* Windows 10/11, [Node.js](https://nodejs.org) 22.12+ (перевірено на 26).
* `npm install`: ставить усе й завантажує Electron.

## Команди

| Команда | Що робить |
|---|---|
| `npm run dev` | адмінка в режимі розробки (гаряче перезавантаження UI) |
| `npm run agent:dev` | агент локально на `127.0.0.1:7420` у **dry-run** (нічого не видаляє і не вимикає), ключ береться з налаштувань адмінки |
| `npm test` | тести (77), зокрема черга `maxConcurrentUpdates`, перевірка sha256 у самооновленні, пороги дисків, очищення браузерів на справжніх файлах, наскрізний адмінка ↔ агент, безпека junction на справжньому NTFS, справжній запуск репортера сесії і вебхук на локальний HTTP-сервер |
| `npm run typecheck` | перевірка типів усіх пакетів |
| `npm run build:agent` | `apps/agent/dist/package/`: `VadeAgent.exe`, служба (WinSW), `install.cmd` |
| `npm run build:admin` → `npm start` | зібрати й запустити адмінку без інсталятора |
| `npm run dist` | інсталятор `apps/admin/release/VadeLauncher-Setup-<версія>.exe` (агент вшитий усередину) |

Щоб побачити «живий» ПК без клубу: запустіть `npm run dev`, потім `npm run agent:dev`
і додайте в адмінці ПК з IP `127.0.0.1`.

## Розгортання в клубі

1. **Головний ПК.** Встановіть `VadeLauncher-Setup-*.exe` (або `npm run build:admin && npm start`).
   При першому запуску створюються `pcs.json` зі списком клубу та випадковий ключ клубу.
   Увімкніть «Запускати разом з Windows»: нічний WoL працює, лише поки адмінка запущена (вона живе в треї).
2. **Пакет агента.** «Налаштування → Експортувати пакет агента» на флешку чи в мережеву папку.
   Пакет містить ключ клубу, тож після встановлення його не варто залишати на ігрових ПК.
3. **Кожен ігровий ПК.** Запустіть `install.cmd` (попросить права адміністратора). Інсталятор:
   * ставить службу `VadeAgent` (LocalSystem, автозапуск, перезапуск при збої);
   * налаштовує живлення: `powercfg /hibernate on`, `RTCWAKE 1`, `CONSOLELOCK 0` і політику
     `HKLM\SOFTWARE\Policies\Microsoft\Power\PowerSettings\0e796bdb-100d-47d6-a2d5-f7d2daa51f51` `ACSettingIndex` / `DCSettingIndex` = 0
     (без пароля після сну, щоб SENET показував клієнтський екран; політика сильніша за схему живлення). Служба повторює все це при кожному старті;
   * вмикає Wake-on-LAN на мережевій карті, відкриває TCP 7420 у брандмауері;
   * видаляє застарілу планову задачу «Club Night», якщо вона лишилася від старих скриптів.
4. **Вхід SteamCMD.** Виберіть ПК → «Вхід SteamCMD» → пароль (+ код Steam Guard). Це робиться один раз на кожен ПК:
   кешований вхід SteamCMD належить обліковому запису служби (SYSTEM). Пароль ніде не зберігається.
5. **Перевірка.** Кнопка ▶ «Обслуговування зараз» на одному ПК — це тестовий запуск без вимкнення. Хід видно в живому лозі (подвійний клік по картці).
6. **Детектор і SENET.** Сядьте за ПК із SENET на екрані входу, відкрийте живий лог цього ПК і натисніть «Це екран входу SENET». Детектор
   запам'ятає процес і заголовок вікна. Якщо SENET має білий список процесів, дозвольте `powershell.exe` і `conhost.exe`: через них працює
   репортер активності в сесії гравця.
7. **Сайт (необов'язково).** Розгорніть приймач з [docs/SITE_INTEGRATION.md](docs/SITE_INTEGRATION.md), впишіть URL і токен
   на вкладці «Інтеграція з сайтом», натисніть «Тест підключення» й увімкніть синхронізацію.

Видалення агента: `C:\Program Files\VadeAgent\uninstall.cmd` (`-Purge` — разом із логами та ключем).

## Що відбувається вночі (ПК №N)

```
слот = старт + (N − 1) × крок
слот − 2 хв   адмінка шле Wake-on-LAN, якщо ПК не на зв'язку (повтор кожні 2 хв до слот + 10 хв)
слот − 2 хв   задача Windows WakeToRun будить ПК зі сну / гібернації сама (навіть без адмінки)
слот          агент запускає завдання сам (якщо ПК запізнився — до 30 хв після слоту)
              якщо за ПК гравець — «Skipped: PC is occupied by a player», Steam не чіпається; повтор до 30 хв після слоту
              закрити Steam → TEMP → логіни → кеш → [userdata] → Майстерня → SteamCMD → дія після (30–60 с)
```

## Важливо знати

* **Smart App Control (Windows 11).** На ПК, де він увімкнений, Windows може блокувати непідписані `.exe`.
  `npm run dist` враховує це під час збірки (uninstaller витягується без запуску проміжного exe, див. `apps/admin/scripts/dist.mjs`),
  тож інсталятор збирається і на ПК з SAC. Запуск самої програми SAC вирішує окремо на кожному ПК: на ПК розробки її заблоковано
  (там працює `npm start`), на адмінському ПК клубу інсталятор запускається.
  Для продакшну варто підписати `Vade Launcher.exe`, `VadeAgent.exe` і `VadeAgentService.exe` сертифікатом
  (electron-builder підписує автоматично, якщо налаштувати `win.signtoolOptions` / Azure Trusted Signing).
  Інсталятор агента попереджає, якщо SAC увімкнений.
* **Оновлення агента по мережі** працює для агентів, починаючи з 0.3. Агенти 0.1–0.2 вперше оновлюються через `install.cmd`.
  Коли адмінка вперше роздає оновлення, Windows може спитати дозвіл брандмауера для Vade Launcher — дозвольте для приватної мережі.
* **Режим «Чергою»** вимагає, щоб адмінка працювала вночі (агенти в цьому режимі самі не стартують). Режим «Кроком» працює й без неї.
* **Sleeping** адмінка показує, коли агент сам повідомив про сон/гібернацію перед відключенням. Після перезапуску адмінки такий ПК показується як Offline.
* **Wake-on-LAN** зі стану «вимкнено» залежить від BIOS (ErP/Deep Sleep має бути вимкнено). Зі сну й гібернації ПК також прокидається таймером RTC.
